# 从零开始学习路线与环境搭建

下一步：[[01-技术基础/Python/测试自动化基础/01-Python操作基础|01-Python操作基础]]

> [!abstract] 这套教程适合谁
> 适合没有 Python 基础，或会复制代码但不清楚项目结构、虚拟环境、依赖、测试运行方式的初学者。学完后，你能用 Python 编写接口和网页自动化测试，并用 pytest 组织用例、用 Allure 生成报告。

## 1. 六个工具分别做什么

| 工具 | 一句话解释 | 典型用途 |
|---|---|---|
| Python | 编写自动化程序的语言 | 写脚本、封装工具、处理数据 |
| pytest | Python 测试运行器 | 收集、执行、断言和组织测试 |
| requests | HTTP 客户端库 | 调接口、传参数、检查响应 |
| Selenium | 浏览器自动化框架 | 操作 Chrome、Edge、Firefox |
| Playwright | 现代浏览器自动化框架 | Web E2E、自动等待、Trace |
| Allure | 测试报告工具 | 展示步骤、附件、截图和趋势 |

它们通常这样组合：

```text
Python
├─ pytest：负责组织和运行测试
├─ requests：负责接口测试
├─ Selenium：负责传统 Web UI 测试
├─ Playwright：负责现代 Web UI 测试
└─ Allure：负责汇总测试结果和证据
```

## 2. 推荐学习顺序

1. Python：变量、容器、判断、循环、函数、异常、文件和模块；
2. pytest：用例发现、断言、fixture、参数化、标记；
3. requests：请求、响应、鉴权、Session、超时、异常；
4. Selenium：定位元素、等待、操作、截图、Page Object；
5. Playwright：Locator、自动等待、断言、上下文、Trace；
6. Allure：结果目录、报告、步骤、附件、失败截图；
7. 综合项目：把接口、网页、报告和配置组合起来。

## 3. 安装 Python

从 [Python 官方网站](https://www.python.org/downloads/) 下载 Windows 安装程序。

安装时建议勾选：

- `Add python.exe to PATH`
- `Install launcher for all users`

安装后重新打开 PowerShell：

```powershell
python --version
python -m pip --version
```

如果 `python` 命令跳到 Microsoft Store，可尝试：

```powershell
py --version
py -m pip --version
```

后续教程中的 `python` 可替换为 `py`。

## 4. 创建第一个项目

```powershell
New-Item -ItemType Directory -Force -Path 'D:\python-test-lab' | Out-Null
Set-Location 'D:\python-test-lab'
python -m venv .venv
```

激活虚拟环境：

```powershell
.\.venv\Scripts\Activate.ps1
```

成功后，命令行左侧通常会出现 `(.venv)`。

如果提示禁止运行脚本，只为当前 PowerShell 进程临时放开：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

退出虚拟环境：

```powershell
deactivate
```

> [!tip] 为什么要用虚拟环境
> 每个项目拥有独立依赖，避免项目 A 升级 pytest 后导致项目 B 无法运行。`.venv` 不应该提交到 Git。

## 5. 安装本套教程依赖

激活 `.venv` 后执行：

```powershell
python -m pip install --upgrade pip
python -m pip install pytest requests selenium pytest-playwright allure-pytest
python -m playwright install chromium
```

检查：

```powershell
python --version
python -m pytest --version
python -c "import requests; print(requests.__version__)"
python -c "import selenium; print(selenium.__version__)"
python -m playwright --version
```

保存依赖：

```powershell
python -m pip freeze > requirements.txt
```

其他人在新环境中恢复：

```powershell
python -m pip install -r requirements.txt
python -m playwright install chromium
```

## 6. 推荐目录结构

```text
python-test-lab/
├─ .venv/                 # 本地虚拟环境，不提交 Git
├─ config/                # 环境配置
├─ data/                  # 非敏感测试数据
├─ pages/                 # 页面对象
├─ utils/                 # 通用工具
├─ tests/
│  ├─ api/                # requests 接口测试
│  └─ web/                # Selenium/Playwright 测试
├─ artifacts/             # 截图、Trace 等本地产物
├─ allure-results/        # Allure 原始结果
├─ conftest.py            # pytest 公共 fixture
├─ pytest.ini             # pytest 配置
├─ requirements.txt
└─ .gitignore
```

`.gitignore` 示例：

```gitignore
.venv/
__pycache__/
*.pyc
.pytest_cache/
allure-results/
allure-report/
artifacts/
.env
```

## 7. 初学者必须养成的习惯

- 使用 `python -m pip`，确认 pip 属于当前 Python；
- 每个网络请求设置超时；
- 不把用户名、密码、Token 写进代码；
- 每条测试既检查技术结果，也检查业务结果；
- 用例之间相互独立；
- 失败时保留响应、日志、截图或 Trace；
- 不在生产环境练习写入和删除接口；
- 修改前先查看 Git 状态，提交时只提交相关文件。
